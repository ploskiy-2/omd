# omd

Python homework for the AAA course.

## Structure

```
omd/
├── basic-python/
│   ├── task1.py
│   ├── task2.py
│   ├── task3.py
│   ├── task4.py
│   └── task5.py
├── .gitignore
└── README.md
```

## Requirements

Solutions use only the python standard library, with no third-party dependencies

## Build

1. Clone this repository and navigate to the project directory:

   ```bash
   git clone https://github.com/ploskiy-2/omd.git
   cd omd
   ```

## Run 

1. Run each script separately 

```bash
python3 basic-python/task1.py
python3 basic-python/task2.py
python3 basic-python/task3.py
python3 basic-python/task4.py
python3 basic-python/task5.py
```
